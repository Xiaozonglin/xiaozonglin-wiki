## 绪论

集成电路厂商将ALU（Algebra Logic）和控制器整合起来，称为CPU，也叫微处理器。

CPU和IO、存储器之间需要传输数据信息、控制信息和地址信息，对应就有数据总线、控制总线和地址总线。CPU厂商将CPU上的引脚进行复用，需要**总线形成电路**将复用的引脚转变为单独的DB、AB、CB。CPU引脚上的电压有限，总线形成电路可以增强CPU对IO和存储器的控制能力。CPU上的引脚也是总线，称为微处理器级总线。

存储器包含：ROM和RAM

- ROM（程序存储器）掉电不丢失数据，存储BIOS，一般只读不写。计算机通电后第一个执行的就是BIOS，它对内存进行质检，初始化IO电路，并从磁盘中读取操作系统到内存。
- RAM（数据存储器）掉电会丢失数据，也就是我们常说的内存。

部分CPU内部有存储器，8086 CPU内没有存储器电路。

CPU对RAM的读写操作：

- 数据总线传输信息
- 地址总线传输内存单元的地址
- 控制总线由CPU根据“读/写”输出不同的命令（存储器写控制引脚一般为WR非或WE非，读控制引脚一般为OE非）

指令：一组二进制代码，告诉CPU做什么、怎么做

机器语言：使用二进制代码编写程序，CPU直接能认识和执行，但可读性差

将机器语言用符号描述为汇编语言，汇编语言程序在执行前需要翻译为二进制代码，这个过程叫**汇编**（高级语言这一步叫作编译）

任何IO设备和CPU之间不能直接通讯，必须在设备与CPU之间（或设备与系统总线之间）设计接口电路，称为**I/O接口电路**，例如显卡、声卡等等。I/O接口地址就是给I/O接口电路分配的地址，CPU对接口的操作演变为对接口地址的操作（和存储器的读写用同一种地址总线，通过不同的控制命令进行区分）。I/O地址译码电路负责将一串地址翻译为给I/O电路控制的一个电路一个命令。

存储器由存储器单元构成，内部存储二进制数据，按字节组织。CPU地址总线的条数决定CPU能管理（寻址）的存储空间的大小。寻找要读写操作单元的地址称为**寻址**，寻址方式越多汇编语言书写越灵活。数据总线条数的多少决定CPU一次能传输的有符号数的范围。8086 CPU是16位的，占两个字节，称为一个**字**，低八位数据称为**低字节**，高八位数据称为**高字节**。任意相邻的两个字节单元可以组成一个**字**，字的地址为字的低地址单元的地址。低字节存放在低地址，高字节存放在高地址。

## 计算机中的数制与码制

计算机中的数均用二进制表示，CPU只认识二进制数。

为了提高运算速度，势必要将一部分运算数据存放在CPU内部，CPU内部少量暂存数据的部件称为**寄存器**。8086 CPU内的8位寄存器有AL、AH，AL作低八位，AH作高八位合成一个16位寄存器AX，还有BL、BH、CL、CH、DL、DH，可以合成BX、CX、DX。

二进制数的运算：首先弄清参与运算的字长（是字节的运算还是字的运算）

二进制加法逢二进一，减法位对位减不够往前借一

```asm
MOV AL, 97
ADD AL, 89
SUB AL, 89
```

`mov`是指令助记符，AL称为目的操作数，97为源操作数

数据必须用0到9开头，例如十六进制数B3H需写成0B3H。名称必须用字母开头。

处理器状态字寄存器PSW，又称标志寄存器

运算溢出的判断：加法时数值位有进位到符号位吗，减法时数值位的最高位有向符号位借位吗

二进制数的逻辑运算：与、或、非的指令助记符
