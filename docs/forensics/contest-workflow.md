# 断网环境下的取证团队协作工具

基于长安杯取证比赛的操作，断网，有交换机和网线将队伍的三台电脑组成一个内网。后面在赛场试了一下发现比赛的Wi-Fi并没有做隔离，所以直接用比赛的网络进行传输。

## 沟通

沟通分为两块，一个是文本的传输，一个是文件的传输。

文本的传输可以用kunpad开一个内网的聊天室，例如

```sh
npx kunpad -n linlinzzo --port 12345
```

这边指定一个端口是因为这个应用并没有管理功能和加入密码，所以比赛的三个人规定一个其他端口来保证交流的秘密性。

文件传输用localsend，该软件的高级设置同样支持设置另外的端口，保证三个人且仅有队伍的三个人在同一个端口。
