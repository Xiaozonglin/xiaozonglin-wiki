# 幻觉与缸中之脑

## 怀疑论

我们不可能认识世界，所以我们只能够及时行乐。——皮浪

只有一件事我知道，这就是我一无所知。——苏格拉底

恩培里克怀疑论立场：怀疑派是一种以任何一种方式把现象和判断放置在反题上的能力，并且因为对象和反对的论证力量相等首先造成对判断的悬置，然后达到精神的宁静。

达到精神宁静的六个步骤：

- 人们总是要寻求知识和宁静
- 但他不可避免地发现知识是不可能的，知识不能带来宁静
- 所有发现知识的尝试，都会导致失望和受苦，除非把宁静建立在它上面
- 如果这是真的，接受知识就是不可能的
- 这就走向了拒绝判断（悬置），因此阻止了更多的失望
- 作为一种偶然发现，人们就得到了宁静状态，而这正是他通过追求知识所寻求的东西

我们研究知识是为了获得真理，还是为了寻求宁静？

怀疑论的几个关键词：

- 现象：通过感觉得到的事物表象
- 判断：对现象做出的肯定或否定的论证
- 反题：对每个判断的否定
- 转义：平衡不同论证的方式
- 悬置：拒绝对现象的判断
- 窃取命题：使用未经证明的假定做出论证、
